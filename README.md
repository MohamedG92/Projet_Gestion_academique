# Projet_Gestion_academique
Système de gestion académique en C++ connecté à une base de données MariaDB (XAMPP). Deux rôles : Enseignant (ajout/modification/suppression d'étudiants, modules, notes et statistiques) et Étudiant (consultation des notes, moyenne générale et note minimale requise à l'examen). Les évaluations sont réparties en TP (20%), CC (30%) et EXAM (50%).
